Cryptography · RSA Algorithm, Factoring Challenge & Attacks

Aim of the Experiment

To implement, analyze, and evaluate the RSA Public-Key Cryptosystem, explore the mathematical hardness of prime factorization of the modulus n, and demonstrate the vulnerability of unpadded ("textbook") RSA against a Chosen Ciphertext Attack (CCA).

Key Objectives of this Experiment

  • Understand the foundational number-theoretic concepts: prime numbers, Euler's totient function φ(n), coprimality, and modular multiplicative inverses.
  • Experience the Factoring Challenge: observe firsthand why RSA security depends entirely on the secrecy of primes p and q, and how knowing n allows recovering the private key once factored.
  • Step through key generation, encryption of a user-defined plaintext, and decryption of the ciphertext.
  • Demonstrate the multiplicative homomorphic property of unpadded RSA, enabling an adversary to decrypt intercepted ciphertexts using a chosen ciphertext attack.
  • Learn the industry-standard mitigation strategies, specifically Optimal Asymmetric Encryption Padding (OAEP - PKCS #1 v2.1).

Theoretical Background

1. Introduction to RSA Cryptosystem

Invented in 1977 by Ron Rivest, Adi Shamir, and Leonard Adleman, the RSA algorithm is one of the first asymmetric public-key cryptosystems widely used for secure electronic data transmission. Unlike symmetric ciphers (such as AES) where both parties share the same secret key, RSA uses a public key for encryption and a distinct private key for decryption.

2. Mathematical Principles & Key Generation

Step 1: Select two distinct prime numbers, p and q.

Step 2: Compute their product, the modulus: n = p × q. The length of n (in bits) is the key length.

Step 3: Compute Euler's totient function: φ(n) = (p − 1)(q − 1).

Step 4: Select a public exponent e such that 1 < e < φ(n) and gcd(e, φ(n)) = 1 (coprime to φ(n)).

Step 5: Compute the private exponent d as the modular multiplicative inverse of e modulo φ(n):

d × e ≡ 1 (mod φ(n))  ⇒  d = e−1 mod φ(n)

The Public Key consists of the pair (e, n) and is openly shared with the public. The Private Key consists of (d, n) and must remain confidential.

3. Encryption and Decryption

To encrypt a plaintext message M (represented as an integer where 0 ≤ M < n):

C = Me mod n

The receiver decrypts the ciphertext C using their private exponent d:

M = Cd mod n

Correctness Proof: By Euler's Theorem, since e × d ≡ 1 (mod φ(n)), there exists an integer k such that e × d = kφ(n) + 1. Hence:

Cd ≡ (Me)d ≡ Mkφ(n) + 1 ≡ (Mφ(n))k × M ≡ 1k × M ≡ M (mod n).

4. The Prime Factorization Problem

The security of RSA relies on the computational asymmetry of multiplication vs. factorization: multiplying two primes p and q is instantaneous, but finding p and q given only n is computationally intractable for sufficiently large primes (e.g., 2048 to 4096 bits).

Security Principle: If an eavesdropper can factor the public modulus n into p and q, they can immediately compute φ(n) = (p − 1)(q − 1), and then calculate Bob's secret private key d = e−1 mod φ(n).

5. The Chosen Ciphertext Attack (CCA) on Textbook RSA

Textbook RSA exhibits a multiplicative homomorphic property:

(M1e mod n) × (M2e mod n) ≡ (M1 × M2)e mod n

If an attacker intercepts ciphertext C = Me mod n, they can choose a random integer R (where gcd(R, n) = 1) and create a blinded ciphertext:

C' = (C × Re) mod n

If the attacker convinces Bob (or a decryption oracle) to decrypt C', Bob computes:

M' = (C')d mod n = (M × R) mod n

The attacker then calculates R−1 mod n and recovers the secret plaintext M without knowing the private key d:

M = (M' × R−1) mod n

Step-by-Step Experimental Procedure

Follow these steps systematically in the interactive simulation module:

  1. Observe the Dynamic Modulus:

    When the simulation loads, a random semiprime modulus n is generated and displayed. Note that a different n is generated on every reload.

  2. Solve the Factoring Challenge (Mandatory):

    To simulate cracking the key or uncovering the underlying factors, calculate the two prime factors p and q such that p × q = n. Enter both values in the input fields and click Verify Factors. You cannot proceed to the subsequent steps until this challenge is solved.

  3. Calculate Euler's Totient φ(n):

    Using your discovered primes p and q, compute φ(n) = (p − 1) × (q − 1). Enter your answer and verify it.

  4. Derive the Private Key Exponent d:

    Review Bob's public exponent e (chosen coprime to φ(n)). Calculate the private exponent d such that (d × e) mod φ(n) = 1. Enter d to unlock Phase 2.

  5. Encrypt a Secret Message (Alice → Bob):

    In Phase 2, select an integer plaintext message M within the valid range (2 ≤ M < n). Compute the ciphertext C = Me mod n and submit it.

  6. Decrypt the Intercepted Ciphertext (Bob):

    In Phase 3, simulate Bob decrypting the transmitted ciphertext using private key d: M = Cd mod n. Confirm that the decrypted message matches Alice's original plaintext.

  7. Execute the Chosen Ciphertext Attack:

    In Phase 4, act as an adversary intercepting C. Choose a blinding multiplier R, construct C' = (C × Re) mod n, send it to Bob's decryption oracle to obtain M', and recover the original plaintext M without d.
